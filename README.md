## 🎮 Narrativa do Jogo
Urban Chase coloca o jogador em uma perseguição entre policial e fugitivo dentro de um cenário urbano.  
O objetivo não é apenas vencer a perseguição, mas reduzir os danos ao patrimônio público durante a partida.

## 🤖 Para os Curiosos: Mecânicas do Jogo
- <ins>Funcionamento</ins>: o jogador controla o veículo em um ambiente urbano com obstáculos e elementos interativos.
  - Sistema de perseguição (policial vs. fugitivo)
  - Penalidade de pontuação por destruição de itens do cenário
  - Planejamento tático com posicionamento de barreiras
- <ins>Objetivo</ins>: capturar/escapar com o melhor desempenho e menor impacto urbano.
- <ins>Sistema de progressão</ins>: o jogador passa por cenas de menu, planejamento e partida principal.
- <ins>Tema</ins>: conscientização sobre os impactos sociais de perseguições em espaços urbanos.

## 🎨 Design do Jogo
Estilo visual 3D com assets urbanos low poly, foco em legibilidade de cena e gameplay direto.

## 🚀 Instalação (baixar e abrir)
### Opção A - Clonar com Git (recomendado)
```bash
git clone https://github.com/2026-1-MCC1/Projeto1.git
cd Projeto1
```

### Opção B - Baixar ZIP
- No GitHub, clique em `Code > Download ZIP`
- Extraia o arquivo

### Opção C - Executável (quando disponível)
- O executável será distribuído via **itch.io**.
- Na pasta `executavel/` do repositório, haverá um **PDF** com o link oficial para download.
- Abra o PDF, acesse o link do itch.io e **baixe ou jogue por lá mesmo**.

## 🛠 Configuração para Desenvolvimento
- [X] Instale o [Unity Hub](https://unity.com/download)
- [X] Instale/abra o Unity Editor `6000.3.6f1` (versão registrada no projeto)
- [X] No Unity Hub, escolha `Add project from disk`
- [X] Selecione `src/Entrega 2/Frontend/PI_CADD` (versão mais atual)
- [X] Abra a cena inicial em `Assets/Scenes/Menu.unity`
- [X] Pressione `Play` para executar

## 🤝 Como Contribuir (passo a passo)
### 1. Clone (e fork apenas se necessário)
- Se você tem permissão no repositório oficial, use apenas o clone direto:
```bash
git clone https://github.com/2026-1-MCC1/Projeto1.git
cd Projeto1
```

- Se você NÃO tem permissão de escrita, faça fork e depois:
```bash
git clone https://github.com/SEU-USUARIO/Projeto1.git
cd Projeto1
git remote add upstream https://github.com/2026-1-MCC1/Projeto1.git
```

### 2. Crie sua branch
```bash
git checkout -b feat/nome-da-feature
```

### 3. Desenvolva e teste
- Abra `src/Entrega 2/Frontend/PI_CADD`
- Faça alterações pequenas e objetivas
- Teste as cenas impactadas no Play Mode

### 4. Commit
```bash
git add .
git commit -m "feat: descrição objetiva da alteração"
```

### 5. Push
```bash
git push origin feat/nome-da-feature
```

### 6. Pull Request
- Abra `Compare & pull request` no GitHub
- Descreva o que foi feito e como testar
- Inclua print/vídeo quando houver mudança visual
